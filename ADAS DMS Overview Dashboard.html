ADAS vs DMS — จำนวนการแจ้งเตือนทั้งหมด

ดูเป็นตัวเลข (ตาราง)

ADAS — แยกตามชนิด Alarm

คลิกที่ชื่อ Alarm เพื่อซ่อนหรือแสดงเส้น กราฟจะปรับสเกลใหม่ตามเส้นที่เหลือ

ดูเป็นตัวเลข (ตาราง)

DMS — แยกตามชนิด Alarm

Distraction และ No driver มีจำนวนมากกว่าชนิดอื่นหลายเท่า ซ่อน 2 เส้นนี้เพื่อดูชนิดที่เหลือชัดขึ้น

ดูเป็นตัวเลข (ตาราง)

ผลการตรวจสอบ (Result)

รวมทุกวันในช่วงที่เลือก · True = แจ้งเตือนถูกต้อง, False = แจ้งเตือนผิดพลาด, Not Checked = ยังไม่ได้ตรวจสอบ

คลิก True / False / Not Checked เพื่อดูว่าเป็น Alarm ชนิดไหน รถคันไหน เกิดเมื่อไร ผู้ขับคนใด และสถานที่ใด · คลิกซ้ำเพื่อปิด

ผู้ขับที่ตรวจพบมากที่สุด

นับจากรายเหตุการณ์ ADAS และ DMS ในช่วงวันที่ที่เลือก · ซ้าย = ทุกผลการตรวจสอบ, ขวา = เฉพาะ True (ตรวจพบถูกต้อง)

คลิกชื่อผู้ขับเพื่อดูตารางว่าขับรถทะเบียนไหน วันที่ใด เวลาใดเกิด Alarm

แนวโน้มพฤติกรรมผู้ขับ — ดีขึ้นหรือแย่ลง

เทียบจำนวนการแจ้งเตือนของผู้ขับแต่ละคนระหว่าง 2 เดือนที่เลือก · แดง ▲ = เพิ่มขึ้น, เขียว ▼ = ลดลง · คลิกการ์ดเพื่อกรอง

รถที่มีการแจ้งเตือนมากที่สุด

เรียงตามช่วงวันที่ที่เลือก · คลิกแถวเพื่อดูว่าใครขับรถคันนั้น วันไหน เวลาใด

สถานะข้อมูลที่เก็บไว้

วันที่ที่ไม่มีข้อมูลจะเว้นเส้นกราฟไว้ ไม่นับเป็นศูนย์
